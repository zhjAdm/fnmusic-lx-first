# 软件内升级实现计划

> 后续实机已否定本文的CLI覆盖升级路径。0.1.14改用守护进程升级接口，见2026-11-06-daemon-upgrade-fix.md；本文保留原实现记录。

**Goal:** 在现有软件更新页增加管理员主动触发的下载并升级，使用 fnOS 原生安装器覆盖升级本应用。

**Architecture:** `SelfUpgrade` 管理私有安装副本、FPK 身份验证、持久状态和独立 systemd 任务。`Updater` 串联已有下载校验与升级交接。系统 `/bin/bash` 执行保存在私有数据目录的固定脚本，避免升级停止管理服务时任务被杀死。

**Tech Stack:** Python、FastAPI、systemd-run、appcenter-cli、Bash、pytest、原生 JavaScript。

设备证据：用户在 fnOS 1.2.1 root 下确认 `/usr/local/bin/appcenter-cli install-fpk [fpk]`；帮助明确 `--volume` 在升级时忽略，说明命令涵盖升级场景。尚未执行真实覆盖升级。
