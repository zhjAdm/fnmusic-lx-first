# LX First Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 保留飞牛官方 App，接入 LX 在线源、收藏下载和虚拟推荐歌单。

**Architecture:** FastAPI Unix Socket 代理，httpx 分离官方和音源请求，SQLite 存储歌曲快照、收藏和任务。lxserver v2.1.2 提供搜索及脚本运行；代理控制播放与落库策略。

**Tech Stack:** Python 3.11+, FastAPI, httpx, uvicorn, mutagen, SQLite, ffprobe, lxserver v2.1.2.

## Global Constraints

- 普通播放不落盘音频；仅喜欢触发下载。
- 官方数据库不写入；凭证不落任务库；付费脚本不分发。
- 手机 302 后自动回退不作保证；提供 proxy 模式。
- 使用独立开发分支；不连接或修改 NAS，除非用户提供连接目标。
