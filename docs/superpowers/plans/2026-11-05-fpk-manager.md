# FPK packaging and manager implementation plan

用户要求直接交付可安装 FPK；随后明确音源脚本和下载目录在启动后的界面设置，并增加接管官方音乐开关。

## 确定行为

- x86_64、ARM64 各生成一个自带运行环境的 FPK，不在安装时 apt/pip 修改 NAS 系统环境。
- 安装后只启动私有音源服务和管理页，默认不接管官方音乐。
- 飞牛桌面管理员网关进入管理页；独立 root Unix Socket，只接受网关注入的管理员身份。界面上传 LX 文件、保存下载目录和播放模式，显式切换官方接管。
- 配置留在 TRIM_PKGVAR；停止应用恢复官方直连，保留设置；卸载在应用目录之外备份设置，不删除用户音频。
- 付费源不预置于公共安装包；用户在界面上传自己的脚本。

## 执行顺序

- [x] 编写管理接口、认证、默认关闭、配置校验与接管开关回归测试。
- [x] 实现管理服务、配置事务与响应式界面；查看实际渲染。
- [x] 实现安装/升级/停止/卸载生命周期，测试安装路径转义和状态保留。
- [x] 锁定并校验 Linux Python、Node、FFmpeg、LX 和 Python 依赖，构建两种架构的 FPK。
- [x] 官方 fnpack 构建、解包检查、Linux 运行时检查、完整回归；独立审查后交付。

NAS 安装运行仍需实机验收，不将结构校验或容器检查描述成真实应用中心安装成功。
