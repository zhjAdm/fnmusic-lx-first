# FFmpeg 按需使用设计

用户已授权移除或按需下载 FFmpeg。本次选择移除 FPK 内置文件并提供管理员主动下载，版本 0.1.2。

- 发现顺序：PATH、官方音乐应用目录的固定候选、扩展数据目录内按需安装版本。分别发现 ffmpeg / ffprobe；校验可执行，ffmpeg 需支持 pipe、AAC 编码和 ADTS 输出。复用现有程序，不修改它们。
- 管理界面显示可用状态、路径和下载进度；仅缺少功能时显示下载按钮。首次安装与播放不会自动联网下载。
- 下载固定日期、固定架构的 LGPL 发布包，校验 SHA256、最大大小和 ELF 架构，仅取 ffmpeg/ffprobe 与许可文件，私有目录原子发布，失败清理临时文件，允许重试。不接受用户提供的下载 URL。
- 缺少 ffmpeg 不阻止启动、搜索与直链/原文件中转；转码返回明确 503。缺少 ffprobe 时喜欢任务先等待组件，不先下载音频，不消耗失败重试次数。
- FPK 构建与 --repack 均移除内置 FFmpeg；Python/Node 保留，下载后的组件放在应用数据区，升级保留。
- 验证发现优先级、功能不兼容、缺失处理、错误校验和/架构/归档路径、管理员权限、重复下载、重打包残留，并检查最终两架构包不含 FFmpeg ELF。
