# fnMusic 管理页视觉调整

用户已确认：保留米白与墨绿，统一图标、字号和间距，减少装饰文案，改善手机触控与状态反馈，保留全部功能。

## 设计方向

- 产品：管理飞牛音乐扩展的在线音源、曲库、推荐及升级
- 气质：沉静、准确，信息以可操作性为先
- 场景：NAS 中的音乐资料柜，保留现有浅色纸面与墨绿
- 重点：音源就绪状态、每日推荐更新时间和操作结果
- 标记：沿用唱片图形，导航采用一致的细线图标

## 原页面审查

- 10px 正文和辅助说明偏小，手机难读：正文14px，说明12px，控件至少44px高
- 英文大写标签和宽字距：移除装饰分区标签，页眉改为中文页面上下文
- 导航使用多个字形符号：使用本地SVG符号集，统一18–20px、1.5px线宽
- 设置页标题与收藏文案偏宣传：标题直接命名功能，说明下载与整理行为
- CSS通过追加覆盖积累不一致尺寸：整理为一套设计变量与响应式规则
- 推荐按钮缺少独立布局：桌面显示状态与操作两列，手机纵向排列

## 边界与实施

按间距、颜色、图标、文案、字体、布局、细节、视觉、动效顺序检查。保留现有元素ID、接口、菜单、功能和分区顺序，不引入远程字体或图标依赖。保留键盘焦点、当前导航语义及减少动态效果设置。字体优先使用设备已有的中文字体，避免 NAS 外网依赖。

验证桌面与手机布局，检查所有菜单及立即刷新推荐、错误提示，运行已有回归测试。不上线、不生成安装包，不自动推送。

设计方法来源：[unslop](https://github.com/heydamir/unslop)，作者 Damir Sokolovsky（[@heydamir](https://x.com/heydamir)），CC BY 4.0。此处沿用其设计检查方法；页面基于项目原有功能和布局调整。

## 完成记录

- 间距：统一4px基准，面板内边距桌面28px、手机20px，分区间距24px
- 颜色：保留米白与墨绿，正文、说明、元信息分别用三种文字角色
- 图标：移除导航与卡片字形符号，采用本地SVG细线符号集
- 文案：页标题直接对应菜单，说明本地优先及MoviePilot目录分离场景
- 字体：中文设备字体，正文14px、辅助12px；手机输入框16px避免聚焦缩放
- 布局：保留分区顺序，桌面双列设置，手机单列与可横向滚动导航
- 细节：控件至少44px高，补跳到内容入口，保留当前页及键盘焦点语义
- 视觉：使用真实状态和推荐更新时间，不添加装饰图片或虚构统计
- 动效：只保留160ms颜色与开关反馈，尊重减少动态效果设置
