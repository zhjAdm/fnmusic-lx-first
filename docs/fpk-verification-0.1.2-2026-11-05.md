# FPK 0.1.2 精简版验证

- 67 项测试通过，1 项 Starlette 测试工具弃用警告；Ruff 和 JavaScript 语法检查通过。
- 管理页面验证缺失组件提示、主动下载与重试按钮；预览夹具不连接 NAS、不下载软件。
- 两种架构均在无网络 Linux 容器中通过真实固定版本归档的校验与安装，验证 AAC 管道转码、ffprobe 音轨探测及再次安装复用、无重复下载。Intel 归档包含不使用的 ffplay，全包扫描上限设置为512 MiB，实际仅安装 ffmpeg/ffprobe 与许可文件。
- 官方 fnpack 1.2.3 构建 x86 / arm 两种 FPK；逐包核对 manifest 校验和、所有当前业务源码和 ELF 架构，不含 FFmpeg、ffprobe、私密脚本和本地配置。
- 缺少 ffprobe 的喜欢任务等待组件、不消耗重试次数，组件可用后继续；缺少 FFmpeg 的转码返回503，搜索与原文件播放可继续。
- 尚未在真实 NAS 验证应用中心安装、桌面网关、官方音乐 App 和扫描歌单链路。
