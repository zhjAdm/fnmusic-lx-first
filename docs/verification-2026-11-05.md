# 2026-11-05 本机验证记录

## 已验证

- 全量测试：40 passed。包括真实 SQLite 持久化、多个用户、取消收藏、质量降档、真实 ffprobe/标签处理、内存 AAC 转码、流关闭和取消时资源释放、扫描中断恢复、搜索快照分页及官方响应形状。
- 实际 Unix Socket：接管、幂等还原、未知端点保留、官方端点重建保护。
- 实际代理进程：启动、SIGKILL 后带所有权日志重启、SIGTERM 正常退出和清理。
- 实际 lxserver v2.1.2：公开发行包 SHA256 校验；补齐 Mac ARM64 平台模块后，以人工脚本验证导入、注册音质声明、取播放链接接口。人工脚本只访问本机测试端点。

- Ruff 静态检查、格式和 Python 编译通过。

测试依赖 Starlette 的 httpx TestClient 产生一条弃用提示，测试结果不受影响；后续升级测试客户端时处理。
