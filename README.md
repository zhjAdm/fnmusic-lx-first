# 飞牛音乐 LX 扩展

为官方飞牛音乐 Web 和手机 App 接入用户自有的 LX 在线音源，提供本地优先播放、每日热门推荐，以及喜欢后下载、整理入库和加入默认歌单的流程。

本项目是社区扩展，非飞牛官方应用。源码版本统一维护在 [fnmusic/__init__.py](fnmusic/__init__.py) 的 `__version__` 中；可下载安装的版本及变更说明以 [Releases](https://github.com/zhjAdm/fnmusic-lx-first/releases) 为准。

[下载安装包](https://github.com/zhjAdm/fnmusic-lx-first/releases/latest) · [反馈问题](https://github.com/zhjAdm/fnmusic-lx-first/issues) · [开发与部署](docs/development.md) · [构建说明](docs/github-build.md)

## 功能

- **本地优先播放**：先通过当前用户的官方曲库匹配歌曲；本地没有可用资源时，再尝试在线直连或 NAS 中转。
- **每日热门推荐**：按北京时间每日刷新，最多保留 30 首，支持管理页立即刷新；只更新歌单信息，不下载音频。
- **音乐探险**：一个歌单混合熟悉风格与相邻风格；在管理页选择舒适、均衡或大胆，默认均衡，各用户分别生成推荐。
- **曲库考古**：一个歌单每天从尚无播放记录、久未播放与随机本地收藏中混合选歌，只返回当前用户可访问的官方曲库歌曲。
- **歌曲版本雷达**：在管理页搜索、分页对比本地歌曲的 Live、伴奏、重制等版本标记、专辑与文件信息，只读分析。
- **喜欢后下载**：先检查已有本地文件，避免重复下载；需要下载时按音源实际支持的最高音质逐级尝试。
- **整理后加入歌单**：支持 MoviePilot 复制或移动文件，等待正式曲库中的歌曲被飞牛收录后，再加入当前用户的默认歌单。
- **本地曲库索引**：递归扫描目录、读取音频标签，支持取消扫描、歌曲搜索和分页查看，不修改音乐文件。
- **扩展管理**：音源上传、音频组件准备、软件更新、日志与搜索播放记录。

普通播放不保存音频文件。手动点击喜欢会创建下载任务；热门推荐、音乐探险、曲库考古和公共歌单本身不会触发下载。

## 安装

### 环境要求

- fnOS 1.2.0 或以上，已安装官方「音乐」应用；实际接口兼容性可能随系统和音乐版本变化。
- Intel / AMD x86-64 或 ARM64 设备。
- 飞牛管理员账号，用于打开扩展管理页和配置应用。
- 用户自行准备的 LX `.js` 音源脚本。可用平台、音质和歌曲资源取决于该音源。

FPK 自带 Linux Python、Node.js 和 LX 服务，无需在 NAS 上另行安装这些运行环境。FFmpeg / ffprobe 优先复用系统已有的兼容版本，缺少时可从管理页按需下载。

### 安装步骤

1. 在 [Releases](https://github.com/zhjAdm/fnmusic-lx-first/releases/latest) 下载与设备架构对应的 `.fpk`：

   | 设备架构 | 文件名格式 |
   | --- | --- |
   | Intel / AMD x86-64 | `fnmusic-lx-first-<版本>-x86.fpk` |
   | ARM64 | `fnmusic-lx-first-<版本>-arm.fpk` |

2. 在飞牛应用中心手动安装；升级已有应用时选择新包覆盖升级。
3. 从飞牛桌面打开「fnMusic 扩展管理」，上传自己的 LX 音源脚本。
4. 在「扩展设置」中填写 NAS 下载目录并保存。
5. 在「本地曲库」中配置音乐目录并扫描。目录设置见下文。
6. 查看「音频组件」状态，按需要准备组件，然后开启「接管官方音乐」。

首次启动默认关闭接管。关闭接管或停止扩展会恢复官方直连；重新启动会恢复已保存的接管偏好。管理页通过飞牛管理员桌面网关访问，不开放独立管理端口。

卸载会先恢复官方直连，不删除应用数据目录之外的音乐文件；扩展数据会备份到所在存储卷根目录的 `fnmusic-lx-first-backup-时间.tar.gz`。备份可能含私有音源和配置，请妥善保管。

## 目录与整理流程

所有路径均填写 **NAS 上的绝对路径**，例如 `/vol1/音乐/下载`。MoviePilot 容器内的路径可能不同，应确认它们映射到同一个 NAS 目录。

### 不使用外部整理工具

下载目录应处于飞牛音乐的扫描范围内，并允许音乐服务账号遍历目录、读取文件。扩展下载完成后，等待飞牛自动或手动扫描，再收藏并加入默认歌单。

### 使用 MoviePilot

将下载目录与正式曲库分开，例如：

```text
/vol1/音乐/
├── 下载/          # 扩展写入，MoviePilot 监控
└── 飞牛音乐库/    # MoviePilot 整理目标
    └── 歌手/
        └── 专辑/
            └── 歌曲.flac
```

对应设置：

| 位置 | 设置 |
| --- | --- |
| 扩展「收藏与下载」 | 下载目录设为 `/vol1/音乐/下载` |
| MoviePilot | 从下载目录整理到正式曲库，支持移动或复制 |
| 扩展「本地曲库」 | 只扫描 `/vol1/音乐/飞牛音乐库`，开启自动更新索引 |
| 飞牛音乐 | 扫描正式曲库 |

下载目录必须位于扩展配置的正式曲库扫描范围之外，扩展才会进入等待整理流程：

```text
点击喜欢 → 检查已有歌曲 → 下载 → 等待整理
        → 匹配正式曲库文件 → 等待飞牛收录 → 加入默认歌单
```

整理可以创建歌手、专辑等子目录。等待期间源文件被移动或服务重启，不会因此自动重复下载；整理未完成或匹配不到时持续等待，不消耗失败重试次数。

扩展索引与飞牛曲库是两套独立索引。扩展不会触发飞牛扫描，也不会把“已扫描”当作“飞牛已收录”。自动索引复用最近 60 秒内的扫描结果；关闭自动索引后需手动扫描。

## 推荐与播放

### 热门推荐

开启接管后，在官方飞牛音乐中打开「热门推荐」歌单即可查看。默认混合酷狗和 QQ 各自返回的首个榜单，交替取歌，按歌曲名和歌手去重（忽略大小写、全半角和多余空白，保留 Live、伴奏等版本标记），最多 30 首。一方不可用时使用另一方结果。`HOT_SOURCE` 默认为 `kg,tx`，也可配置单个平台；`HOT_BOARD` 可为单平台指定榜单。

后台每分钟检查北京时间日期，每天成功更新一次。当天列表持久保存，多用户共用；重启后继续使用，错过的更新会在启动后补上。更新失败保留上一期，每 5 分钟重试。

可在管理页「扩展设置 → 热门推荐」点击「立即刷新推荐」，查看更新时间和歌曲数量。上游榜单未变化时，两次更新的歌曲可能相同；刷新推荐不创建收藏或下载任务。

也可通过 `PUBLIC_PLAYLISTS` 配置公共在线歌单，详见 [开发文档](docs/development.md)。

### 音乐探险、曲库考古与版本雷达

开启接管后，在飞牛音乐歌单中打开「音乐探险」或「曲库考古」，不再为细分模式新增歌单。两个歌单均最多 30 首，不自动下载或收藏。

热门推荐、音乐探险、曲库考古各有一张内置封面，由 NAS 直接提供，不依赖在线图床。封面随应用分发，歌曲更新不会改变歌单封面。

接管模式下，官方「默认歌单」也会显示同系列的专属封面；配置了 `DEFAULT_PLAYLIST_GUID` 时按指定歌单匹配。只替换展示用封面，保留官方歌单及歌曲；关闭接管后恢复官方封面。

「音乐探险」从当前用户的持久播放活动及共享曲库的 Genre 标签统计风格。通过明确配置的相邻风格规则扩展候选，舒适、均衡、大胆分别优先安排约 10%、35%、65% 的新风格候选，资源不足时由其他候选补位；不是音频分析或机器学习评分。候选跨平台去重，排除可识别已播放和本地已有歌曲；无画像或风格候选时使用热门推荐兜底并继续排除。管理页「扩展设置」中的探险程度在下一次生成时生效。

「曲库考古」按北京时间日期稳定混合尚无记录、超过 30 天未播放与随机收藏，候选来自已配置目录的扩展索引，并通过当前用户的官方搜索核对文件路径。每次生成最多核对 90 个候选，并发最多 4 个、查询最多等待 15 秒。时间或资源不足时歌曲可能少于 30 首。歌曲尚未被官方收录、当前用户不可访问或索引未扫描时不会展示；播放和收藏沿用官方歌曲行为。

扩展将可确认用户归属的资源跳转、供流开始等活动聚合保存到私有 `playback.db`，不随日志轮转清空。首次使用尽量导入最近仍保留的 500 条活动中的有效播放记录。它们不代表客户端实际播放成功或听完；没有记录不等于从未听过。普通官方播放复用最近已验证的会话归属，无法确认归属时不计入个人历史。

音乐探险和曲库考古按北京时间为每位用户每天生成一次。后台为有有效会话的用户刷新，错过刷新时在下次访问歌单列表或详情时补上。列表和详情使用同一份结果，重启后继续使用。刷新失败时保留上次成功结果，5 分钟后可重试。当天的新播放记录、收藏和曲库变化在下一次生成时反映。

管理页「版本雷达」按歌名主体和歌手对本地索引分组，仅剥离已识别的版本后缀，保留普通括号内容。分组属于疑似关联，未标注不等于录音室版，文件格式和大小也不能证明真实音质。雷达不修改、移动或删除文件；外部文件变化后，请先在「本地曲库」重新扫描。

### 播放方式与边界

本地匹配使用歌名、歌手、专辑和时长校验，通过当前用户的官方接口播放；已下载文件需先被官方曲库收录。

在线资源可选择「优先设备直连」或「通过飞牛中转」。若手机直连不稳定，可在管理页改用中转。直链返回后，NAS 无法判断手机端是否成功播放，也无法保证在手机直连失败后无缝切换。

断点续传使用同一播放资源，绑定过期后需重新播放。部分 App 的 HLS 兼容播放需要 FFmpeg，通过内存管道输出 AAC；不提供磁盘分段缓存，拖动进度可能需要重新转码。

搜索每次最多读取 100 首在线候选；公共歌单最多读取 100 页。音源声明的资源不保证一定可播放或下载。

## 软件更新

在管理页「软件更新」中检查公开的 GitHub Releases，不需要 GitHub Token。

- **仅下载更新包**：下载匹配设备架构的 FPK 并校验 SHA256，随后可在飞牛应用中心手动安装。
- **下载并升级**：在支持的原生 NAS 环境中，将校验后的安装包交给飞牛应用中心执行覆盖升级。期间扩展会短暂断开，页面会等待新版本管理服务重新连接。

可自定义 NAS 安装包下载目录；留空时使用扩展私有目录的 `updates/update.fpk`。修改目录只影响后续下载，不迁移已有文件。

软件内升级确认成功后，自动清理本次下载包和私有安装副本；失败时保留。清理会核对文件身份和校验值，同名文件被替换时不会误删。手动安装到系统的其他 FPK 文件不在清理范围内。

升级入口依赖飞牛应用中心的本地接口和权限。不支持时请使用手动安装；结果无法确认时不会自动重复提交或卸载重装。本项目不会在后台静默安装新版本。

## 日志与排障

管理页提供「运行日志」与「搜索与播放」记录，支持筛选、刷新和下载，按最新记录在前展示。日志按文件大小轮转，不按时间定期清空；扩展日志单文件上限 1 MiB，保留 3 份历史，启动日志另有大小限制。

| 现象 | 检查方法 |
| --- | --- |
| 推荐未更新 | 点击「立即刷新推荐」，查看返回提示及推荐更新日志；确认 LX 服务与榜单接口可用 |
| 下载后一直等待整理 | 检查 MoviePilot 是否运行、目录映射是否正确，扩展是否只扫描正式曲库并开启自动索引 |
| 已整理但未加入歌单 | 确认飞牛音乐已收录整理后的文件，检查读取权限及歌曲标签；扩展扫描完成不代表官方入库完成 |
| 下载任务等待登录 | 重新登录并访问官方音乐，恢复当前用户的会话 |
| 在线播放失败 | 改用 NAS 中转，查看日志中的上游服务、HTTP 状态及失败阶段 |
| 升级失败或状态未知 | 在飞牛应用中心核对应用状态，保留日志后反馈；必要时手动覆盖升级 |
| 页面仍显示旧版本 | 从飞牛桌面重新打开管理页，核对页面版本与服务版本是否一致 |

提交 [Issue](https://github.com/zhjAdm/fnmusic-lx-first/issues) 时，请提供系统与音乐应用版本、扩展版本、设备架构、复现步骤和相关日志。不要上传音源脚本、Cookie、密钥或完整私有配置；日志与截图可能含歌名、搜索关键词及本地目录，分享前请检查。

## 隐私与许可证

配置、音源脚本、扩展索引和任务状态保存在 NAS。用户会话凭证仅在进程内存中短期保存，收藏和任务按用户隔离。日志会隐藏已知凭证及远端媒体地址，但仍应在分享前检查内容。

只导入自己信任的 LX 脚本。脚本运行在独立服务中，VM 不构成完整安全隔离。项目不附带付费音源、密钥或音乐内容；音源及音乐内容的使用与分发遵循各自授权。
